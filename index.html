Questions

Frequently asked

How does Username-checker work?

For each supported platform, the app either queries a public, browser-accessible endpoint (like GitHub's or GitLab's public API) or, where that isn't possible, gives you a direct link to check the profile yourself.

Is the result 100% accurate?

No. Results from platforms with a live check are generally reliable at the moment of checking, but availability can change instantly, and a small number of edge cases (banned, reserved, or renamed accounts) can produce misleading signals. Always verify anything important directly on the platform.

Why does a platform show "Unknown"?

Most major platforms block cross-origin requests from browsers, require authentication, or use anti-bot protection that a static site can't get past. Rather than guess, we label these Unknown and link you to check manually.

Does Username-checker store my searches?

No. Everything happens in your browser session and nothing is written to a database — this project has no backend by design.

Why can't some platforms be checked?

Browsers enforce CORS (cross-origin resource sharing) rules. Unless a platform explicitly allows requests from other websites, JavaScript running here simply cannot read the response.

Can I check multiple usernames?

Currently one username at a time keeps the interface simple and fast — run another search whenever you like, previous results are replaced instantly.

Can I add more platforms?

Yes — the platform list is a single configuration array in script.js. Adding a new entry with a profile URL and, optionally, a check function is enough to extend coverage.
