Questions

Frequently asked

How is availability determined?

Each platform is checked with logic specific to its own API or public response behavior. A username is only marked Taken when an existing profile is confirmed, and only marked Available when the platform gives a reliable signal that no such profile exists. Anything less certain — a blocked request, a timeout, an ambiguous response — is marked Unknown.

Why is my result Unknown?

Most platforms block cross-origin browser requests, require authentication, or run bot protection that a static site can't get past. Rather than guess, we say Unknown and give you a link to check by hand.

Does Unknown mean Available?

No. Unknown only means we couldn't verify it — never that the username is free. Never treat an Unknown result as an invitation to assume availability.

Can every platform be checked automatically?

No. Only platforms that expose a public, CORS-enabled endpoint can be checked live from a browser. The Platforms section marks exactly which ones those are.

Does Username-checker store my searches?

No. This is a static site with no backend and no database — everything happens in your browser and nothing is logged anywhere by this interface.

Can I manually verify a result?

Yes — every result card, automatic or manual, includes a link straight to that platform's profile page.

Can I add another platform?

Yes. Every platform is a single configuration object in script.js. See the README for the exact shape and an example.
